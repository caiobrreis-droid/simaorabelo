# Simão Rabelo · Personal Trainer

Site oficial de Simão Rabelo, personal trainer em Boa Vista – RR. *Especialista em resultados.*

Página única em HTML, CSS e JavaScript puros, sem build e sem dependências.

## Rodar localmente

Abra `index.html` no navegador, ou sirva a pasta:

```bash
npx http-server -p 5510
```

## Estrutura

- `index.html`: o site inteiro (estilos e scripts embutidos)
- `img/simao-01.jpg`: foto principal
- `img/logo/`: logo em SVG vetorial, PNGs (escuro e branco) e favicon
- `img/resultados/`: fotos de antes e depois e de performance

## Publicar

Por ser estático, pode ser publicado direto no GitHub Pages, Netlify ou Vercel.
